# Lab 06 - Data Products e Acesso (PT-BR)

Este laboratório apresenta a criação de Data Products e o gerenciamento de acesso no Microsoft Purview.

## Objetivos
- Criar Data Products.
- Configurar permissões de acesso.
- Monitorar o uso dos Data Products.

## Passos
1. Acesse o menu 'Data Products'.
2. Crie um novo Data Product conforme as necessidades do negócio.
3. Configure as permissões de acesso utilizando o menu 'Permissions'.
4. Monitore o uso e o histórico dos Data Products.

## Observações
- Os nomes dos recursos e botões permanecem em inglês.
