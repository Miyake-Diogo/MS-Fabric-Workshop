# Lab 07 - OKRs (PT-BR)

Este laboratório aborda a definição e acompanhamento de OKRs (Objectives and Key Results) no contexto de Data Governance com Microsoft Purview.

## Objetivos
- Definir OKRs para governança de dados.
- Relacionar OKRs aos domínios e ativos de dados.
- Monitorar o progresso dos OKRs.

## Passos
1. Acesse o menu 'OKRs'.
2. Defina os objetivos e resultados-chave para cada domínio de governança.
3. Relacione os OKRs aos ativos de dados relevantes.
4. Monitore o progresso utilizando os dashboards disponíveis.

## Observações
- Os nomes dos recursos e botões permanecem em inglês.
