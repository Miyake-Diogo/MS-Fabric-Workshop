# Lab 13 - Funcionalidades Custom API (PT-BR)

Este laboratório apresenta funcionalidades de Custom API no Microsoft Purview.

## Objetivos
- Integrar APIs customizadas ao Purview.
- Gerenciar endpoints e autenticação.
- Monitorar o uso das APIs.

## Passos
1. Navegue até o menu 'Custom API Functionality'.
2. Configure endpoints e autenticação conforme as necessidades do negócio.
3. Monitore o uso das APIs customizadas.
